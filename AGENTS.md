
# Expense Tracker — Agent Instructions

## Project Goal
Build a portfolio-ready personal finance web application.

## Tech Stack
- React + Vite + TypeScript
- Tailwind CSS
- Node.js + Express + TypeScript (strict mode)
- SQLite
- Vitest + Supertest

## Working Rules
1. Read docs/PRD.md before implementing features.
2. Work on one task at a time.
3. Explain the implementation plan before editing code.
4. Ask for approval before major architecture changes.
5. Do not modify unrelated files.
6. Do not install unnecessary dependencies.
7. Do not expose secrets or credentials.
8. Never delete user data without approval.
9. Keep changes small and reviewable.
10. Do not commit or push without approval.
11. Keep the single-user unauthenticated MVP localhost-only; do not expose it through public hosting, tunnels, or LAN listeners.
12. Public deployment is a separate post-MVP phase requiring an approved security model and deployment review.

## Code Quality
- Use descriptive variable and function names.
- Keep components small and reusable.
- Validate data on the backend.
- Store money as integer cents.
- Handle loading, empty, and error states.
- Use database transactions where needed.
- Keep development and test databases separate.

## Testing
- Add tests for important business logic.
- Run relevant tests after implementation.
- Report exact test results.
- Never claim tests passed without running them.

## Communication
- Explain decisions in simple Vietnamese.
- Keep code and technical documentation in English.
- Explain unfamiliar technical concepts.
- Summarize modified files after each task.

## Definition of Done
A task is complete when:
- Acceptance criteria are satisfied.
- Relevant tests pass.
- No known critical errors remain.
- Documentation is updated.
- Changes are ready for human review.

## Language Policy
- English is the official language of this project.
- All UI text, labels, buttons, forms, and error messages must be in English.
- All source code, comments, documentation, and tests must be in English.
- All Git commit messages must be in English.
- All technical reports generated by the coding agent must be in English.
- Do not introduce Vietnamese text into the application or repository.
